Keyboard setups

Ducy Shine 7 and Aula F108 PRO setup keybindings
October 1, 2026 · 1 min · Javier De Carli

Ducy Shine 7#

Keyboard Backligt#

Command Description
Fn + F10 RGB Modes
Fn + F5 Adds one level of Red
Fn + F6 Adds one level of Green
Fn + F7 Adds one level of Blue

Aula F108 PRO#

Light Strip Bar#

Command Description
Fn + Z key Color
Fn + Left Alt Brightness (5 brightness levels)

Side Light#

Command Description
Fn + Right Shift Effects
Fn + /? Color
Fn + Right Alt Brightness (5 brightness levels)

Keyboard Backligt#

Command Description
Fn + “|” RGB modes
Fn + Tab Colors (static pre-confugred colors)
Fn + ↑ / ↓ Brightness (5 brightness levels)
Fn + → / ← Speed (only on RGB modes that have speed)
